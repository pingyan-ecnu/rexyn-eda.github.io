仿真与模拟，支撑3D逻辑折叠技术落地

3DIC的复杂度呈指数级增长，单一验证手段无法覆盖从架构探索到系统验证的全流程。Rexyn 仿真与模拟产品线覆盖软件仿真、硬件仿真、原型验证三级验证体系，与元模型PDE内核和跨层共优化引擎深度联动，确保韬定律3D折叠设计在物理可行域内高效收敛、可靠落地。

L1 · 软件仿真

Simulation

架构探索与功能验证的第一道防线

  • 元模型PDE驱动的快速物理场预测，支撑架构级设计空间搜索
  • 支持网表级功能仿真与电热稳态耦合仿真
  • 与 TauFold-Explorer 联动，快速评估折叠划分方案
  • 低部署成本、高可重用性，适配 IP 开发与 SoC 集成早期阶段
L2 · 硬件仿真

Emulation

大规模3D折叠SoC的加速验证核心

  • 面向 5千万–10亿门级设计规模，支撑完整 SoC 集成验证
  • 硬件仿真加速跨层共优化迭代，缩短收敛周期
  • 支持软硬件集成验证与嵌入式软件早期开发
  • 与 MultiPhys-CoOpt 联动，实现电热耦合物理约束下的加速验证
L3 · 原型验证

Prototyping

真实系统环境下的软硬件协同验证

  • 基于 FPGA 原型平台，提供接近真实的系统运行环境
  • 支持多 FPGA 分割、多 FPGA 调试与协同建模
  • 覆盖软件开发、系统验证与软硬件集成全流程
  • 与 DTCO-Bridge 对接，打通设计-工艺-系统验证链路

仿真-物理-工艺闭环

仿真结果回灌元模型PDE内核，与 TCAD/WAT 工艺数据闭环校准，保障3D折叠设计在制造端可落地。

仿真平台如何支撑3DIC技术落地
01

折叠方案前置评估

软件仿真阶段即可基于折叠互连原语与 RC 时间缩放代价函数，快速量化不同折叠划分方案的功耗、时序与热场收益，避免盲目进入完整版图仿真。

02

跨层耦合加速验证

硬件仿真承接架构级验证结果，在接近真实的规模下验证层间电热耦合、混合键合互连特性，确保跨层共优化结果在系统级仍然成立。

03

软硬件协同与系统验证

原型验证提供真实系统环境，验证3DIC在嵌入式软件、系统负载动态跳变下的时序实时性与热可靠性，覆盖车载、端侧AI等严苛场景。

04

验证收敛与良率前置

三级验证体系与统计工艺变异模型联动，在设计阶段预判工艺偏差与3D隐性失效风险，实现验证收敛与良率优化的同步前置。
